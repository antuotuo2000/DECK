先说结论：DECK 是一家值得长期跟踪的优秀消费品公司，目前的估值已经进入比较有吸引力的区域。

我认为它最有价值的资产不是鞋子本身，而是两大品牌：

  • HOKA： 专业跑鞋、户外运动和生活方式品牌，仍有全球扩张空间。
  • UGG： 具有较强品牌认知度的舒适鞋履和生活方式品牌，具备一定定价能力。

DECK 最吸引我的地方是：品牌资产、较高利润率、强自由现金流、低负债以及持续回购股票。

但要注意一个问题：目前公司的增长速度正在放缓，不能简单地把过去的高速增长外推到未来。

以下采用截至2026年11月13日可获得的最新财报和市场数据。股价采用11月11日收盘数据。

一、公司究竟靠什么赚钱？

DECK 是一家品牌运营公司，而不是传统制造企业。

它主要负责品牌设计、产品研发、营销、渠道管理和全球销售，生产交由第三方制造商完成。

旗下主要品牌：

1. HOKA

专业跑步、越野跑、徒步及日常运动鞋。

FY2026收入约25.87亿美元，增长15.9%

这是公司目前最重要的增长引擎。

2. UGG

雪地靴、拖鞋、凉鞋、休闲鞋及服饰。

FY2026收入约27.39亿美元，增长8.2%

是公司主要的利润和收入基础。

3. Teva

户外凉鞋、徒步鞋等。

规模较小，目前不是主要增长动力。

这里有一个重要区别：

跑鞋技术可以被竞争对手模仿，但消费者对品牌的认可、产品口碑和长期形成的消费习惯，不容易在短时间内复制。

不过，鞋类消费存在时尚周期，品牌护城河并不是永久的。

我重点看六个指标：收入增长、毛利率、净利率、经营利润率、自由现金流和负债。

  • UGG 的增长相对稳定。
  • DECK 的未来价值越来越取决于能否把品牌扩张到更多品类和地区。

这里有一个特别需要注意的问题：

我更关注剔除一次性关税退款之后，DECK 的真实经营利润率能否保持在较高水平。

5. 自由现金流和回购

DECK 具有较强的现金创造能力。

公司FY2026回购了约10.75亿美元股票，FY2027上半年又回购约6.38亿美元。

这说明管理层愿意将现金返还股东。

不过，我认为回购是否创造价值，取决于回购价格：

低估时回购是增加股东价值，高估时回购可能是在浪费现金。

对品牌消费企业来说，打折销售很容易损害长期品牌价值。

需要观察管理层能否在增长放缓时继续保持这种纪律。

我的最终结论

我认为DECK属于值得长期持有研究的优秀消费品企业。

它有几个很好的特点：

  • HOKA和UGG两个具有全球知名度的品牌。
  • 接近20%的净利率。
  • 超过20%的营业利润率。
  • 没有有息借款。
  • 有能力持续回购股票。

但也有明显缺陷：

  • 不是技术垄断型公司。
  • 品牌热度可能出现周期性衰退。
  • 最新季度收入增速只有3.5%。
  • 未来增长需要依赖全球扩张和产品创新。

我的投资判断：好公司，目前价格有吸引力，但我更愿意在70美元附近开始建立仓位，在60–65美元重点买入。

十、我想进一步帮你研究一个关键问题

DECK、ONON、BIRK、CROX 这四家公司其实非常适合做一轮巴菲特式价值投资比较。

我建议下一步直接比较它们的：

  • 过去10年收入、净利润和自由现金流。
  • 真实品牌护城河。
  • ROIC（投入资本回报率）。
  • 库存周转率。
  • 管理层资本配置能力。
  • 当前估值与未来五年预期收益。

这样可以回答一个更重要的问题：如果未来只能选择一家运动消费品牌公司持有5年，究竟应该买哪一家？
